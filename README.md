# voin (voice in)

이 맥의 마이크와 화상회의(Zoom·Teams 등) 소리를 받아써서 Markdown 기록으로 저장하고, 말로 Codex·Claude Code·Grok에 일을 시키는 맥 앱입니다. 회의뿐 아니라 인터뷰·강의·혼자 하는 메모 녹음에도 씁니다. 녹음이 끝나면 누가 말했는지 구분하고(화자 분리), 요약을 붙입니다. 받아쓰기와 화자 분리는 이 맥 안에서만 합니다. 요약은 설정에서 고른 방법에 따라 외부 서버(Anthropic·OpenAI 등)로 기록을 보낼 수 있습니다(Ollama는 이 맥 안).

## 내려받기

[Releases](https://github.com/su-record/voin/releases/latest)에서 DMG를 받습니다. Apple Silicon 맥, macOS 14.4 이상.

| 파일 | 설명 |
| --- | --- |
| `voin-<버전>.dmg` | 기본. 받아쓰기 모델(751MB)은 처음 실행할 때 내려받습니다. |
| `voin-<버전>-with-model.dmg` | 받아쓰기 모델까지 들어 있어 인터넷 없이 설치합니다. |

Apple 개발자 서명이 없는 앱이라 처음 열 때 macOS가 막습니다. 응용 프로그램 폴더의 voin을 **Control-클릭 → 열기**로 한 번 열거나, 시스템 설정 → 개인정보 보호 및 보안에서 **그래도 열기**를 누르세요.

## 실행

응용 프로그램 폴더의 **voin** 앱을 실행합니다. 처음 실행하면 모델을 불러오느라 10초쯤 걸립니다. 화면 맨 위 줄에 받아쓰기 모델 상태가 표시됩니다.

| 메뉴 | 단축키 |
| --- | --- |
| 새 회의 녹음 | ⌘N |
| 녹음 파일 불러오기 | ⌘O (창에 파일을 끌어다 놓아도 됨) |
| 설정 | ⌘, |
| 녹음 시작/중지 (어느 앱에서든) | ⌥R (설정에서 변경) |

화면 오른쪽 위 메뉴 막대 아이콘에서도 녹음 시작/중지, 불러오기, 저장 폴더 열기, 모델 내려받기를 할 수 있습니다. 창을 닫아도 앱은 계속 실행되며(녹음도 계속), ⌘Q로 끝냅니다. 창이 닫힌 상태에서 단축키로 녹음을 시작하면 창이 뒤쪽에 다시 열립니다(닫힌 창에서는 마이크를 받을 수 없어서).

처음 한 번 허용할 권한:
- **마이크**: 녹음을 시작하면 macOS가 묻습니다.
- **시스템 오디오 녹음**(화상회의 소리): 시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음에서 'voin'을 허용합니다.

개발 중에는 `npm start` 후 http://localhost:4310 을 열어 확인합니다. 앱에 반영하려면 다시 빌드합니다.

## 빌드와 팀원 배포

| 명령 | 결과 |
| --- | --- |
| `npm run build:app` | 앱을 빌드해 `/Applications/voin.app`에 설치 (예전 이름 `회의록.app`이 있으면 지움) |
| `npm run build:dist` | 위와 같고, 팀원 배포용 `dist/voin-<버전>.dmg`도 만든다 (앱·설치 안내·테스트 음성 포함, 받아쓰기 모델 제외) |
| `npm run build:dist:offline` | 받아쓰기 모델까지 넣은 `dist/voin-<버전>-모델포함.dmg` (인터넷 없이 설치할 팀원용) |

버전은 `package.json`의 `version` 한 곳에서만 바꿉니다. 앱의 정보 창(voin → voin에 관하여)과 설정 → 정보에 표시됩니다.

앱 안에 Node.js(Apple Silicon용), 서버 코드, 화자 분리 모델이 들어 있습니다. 받아쓰기 모델(751MB)은 기본 DMG에 넣지 않고, 앱을 처음 실행할 때 화면 맨 위 줄의 **내려받기** 버튼으로 Hugging Face에서 받습니다. 받은 모델은 `~/Library/Application Support/voin/models/`에 저장되고, SHA-256으로 손상 여부를 확인합니다. 받는 중 취소하면 받은 곳부터 이어 받습니다. 회사망 인증서 재서명에 대비해 맥 키체인 인증서를 쓰도록(`--use-system-ca`) 실행합니다. 설치 안내 원본은 `docs/팀원-설치-안내.md`입니다.

- 대상: Apple Silicon 맥, macOS 14.4 이상
- Apple 개발자 서명·공증을 하지 않은 앱이라, 팀원은 첫 실행 때 시스템 설정 → 개인정보 보호 및 보안에서 "그래도 열기"를 한 번 눌러야 합니다. 회사에 Apple Developer 계정이 있으면 공증해서 이 단계를 없앨 수 있습니다.

## 직접 테스트하기

- `samples/`에 테스트용 음성이 있습니다. ⌘O로 불러오면 받아쓰기와 화자 분리 결과를 볼 수 있습니다.
  - `4명-테스트.wav`: 같은 음성(Yuna)의 높낮이를 바꿔 만든 4명 대화. 받아쓰기 확인용입니다.
  - `12명-합성음성-테스트.wav`: 맥의 합성 음성 12개. 화자 분리 시험용입니다. 기계음이 섞여 있어 받아쓰기 품질은 낮습니다.
  - `5명-합성회의-정답포함.wav`: 결정·할 일·남은 질문을 심어 둔 6분 40초 회의. 요약 모델 비교용이며 정답과 대본은 `5명-합성회의-정답.md`에 있습니다.
- 정확도는 **실제 회의 녹음**(아이폰 음성 메모의 m4a 등)으로 확인하세요. 합성 음성은 실제 사람 목소리와 특성이 달라 판단 근거가 되지 않습니다.

## 설정 항목

- **저장 위치**: Obsidian 보관함(안의 폴더 지정) 또는 폴더. 처음 실행할 때 Obsidian 보관함이 있으면 지금 열린 보관함의 `녹음 기록` 폴더, 없으면 `~/Documents/녹음 기록`으로 정해집니다(이전 버전에서 쓰던 설정은 그대로 유지).
- **팀 공유**: 녹음이 끝나면 지정한 공유 폴더에 기록 사본을 복사합니다(음성 파일은 복사하지 않음).
- **기록 형식**: Obsidian 속성(날짜·시간·참석자·태그)과 태그
- **받아쓰기**: 언어, 화상회의 소리 기본 포함, 실시간 자막 줄 나누는 기준
- **화자 분리**: 켜기/끄기, 참석 인원(자동 권장)
- **녹음 파일**: 음성을 `첨부/` 폴더에 WAV로 보관할지
- **일반**: 녹음 시작/중지 전역 단축키, 메뉴 막대 아이콘 표시
- **받아쓰기 모델**: 모델별 장단점·속도·스트리밍 지원 여부, 내려받기/취소/사용하기/삭제

설정 파일: `~/Library/Application Support/voin/settings.json`

## 음성 작업 (작업 모드)

위 막대의 **작업**을 고르고 마이크(또는 어디서든 ⌥V)를 누르고 말하면, 말이 1.5초 멈출 때 받아쓴 글을 설정한 도구에 보내 작업 폴더에서 일을 시킵니다(`lib/agent.mjs`). Discodex(Discord ↔ Codex app-server)와 같은 생각을 이 맥 안에서 합니다.

- **Codex:** 공식 `codex app-server`(stdio JSON-RPC)에 폴더마다 지속 thread 하나. 명령·파일 수정 승인 요청은 화면의 허용/거절 카드로 답합니다.
- **Claude Code:** 요청마다 `claude -p --resume <세션>`(stream-json). 허락이 필요한 도구는 `--permission-prompt-tool`로 `lib/approval-mcp.mjs`(작은 MCP 서버)가 voin 화면에 묻습니다.
- 도구에 등록해 둔 MCP 서버·스킬·설정을 그대로 씁니다. 폴더마다 대화가 이어지고 "새 대화"로 새로 시작합니다.
- **권한(설정 → 음성 작업):** 기본은 작업 폴더 안 수정만 바로, 폴더 밖 수정·네트워크·명령은 승인. 읽기 전용, 전체 허용(승인 없음)도 고를 수 있습니다.
- **답 듣기:** 답의 첫 문장을 macOS `say`(유나 목소리)로 읽습니다. 별도 음성 모델은 없습니다.

## 외국어 회의

설정 → 받아쓰기의 언어를 **자동 감지 (여러 언어)**로 두면 외국어로 한 말을 원문 그대로 받아씁니다. 한 언어(예: 한국어)로 고르면 다른 언어로 한 말은 기록에서 빠집니다. **외국어 번역**을 켜면 녹음을 정리할 때 외국어 줄 아래에 `↳ 한국어 번역`을 붙입니다(`lib/translation.mjs`). 번역은 voin 내장 모델로 이 맥 안에서 하며, Gemma 4 E4B·Qwen3.5 9B·Gemma 4 12B만 씁니다(Mi:dm 2.0 Mini는 시험에서 절반을 번역하지 못함). 영어 한 줄에 1~2초 걸립니다. 일본어는 2026-10-17 합성 음성 시험에서 받아써지지 않았고, 자동 감지에서는 한국어 문장 앞부분을 중국어로 잘못 적은 경우가 있었습니다(한국어 고정에서는 없음). 그래서 기본값은 한국어 고정입니다.

## 요약

**기록 다듬기**(설정 → 받아쓰기)를 켜면 정리할 때 "음", "어", "um" 같은 군말과 바로 반복한 말을 기록에서 지웁니다(기본은 들린 그대로).

녹음 정리(화자 분리)가 끝나면 기록 맨 위 `## 요약`에 한 줄 요약·핵심 내용·결정 사항·할 일·남은 질문을 붙입니다(`lib/summarizer.mjs`). 기록 화면의 **요약 만들기/다시 요약** 버튼으로 저장된 기록도 요약합니다. 실패해도 받아쓴 기록은 그대로 남습니다. 요약에 나온 날짜·숫자가 받아쓴 기록에 없으면 요약 아래에 "기록에서 찾지 못한 날짜·숫자" 경고를 붙입니다(`lib/summary-check.mjs`, 한글·영어로 말한 숫자도 읽어 비교). 할 일의 담당자·기한이 기록에 없으면 "담당 미정"·"기한 없음"으로 씁니다.

| 방법 | 필요한 것 | 기록이 가는 곳 |
| --- | --- | --- |
| Claude Code / Codex 명령줄 도구 | 설치하고 로그인 (`claude`, `codex login`). voin은 로그인 정보를 갖지 않고 도구를 불러 씀 | Anthropic / OpenAI |
| ChatGPT 로그인 / Grok 로그인 | 설정에서 **로그인** → 브라우저에서 기기 코드 승인. hermes-agent(0.19.0 `hermes_cli/auth.py`)와 같은 방식으로 Codex CLI·Grok CLI의 로그인(클라이언트 ID)을 빌려 씀 (`lib/oauth-login.mjs`). 토큰은 키체인, 만료 전 자동 갱신 | OpenAI / xAI |
| API 키 (Anthropic, OpenAI, xAI Grok, Google Gemini, OpenRouter) | 설정에 키 등록. 키는 맥 키체인에 저장 | 해당 회사 |
| OpenAI 호환 주소 | 서버 주소(LM Studio·사내 게이트웨이 등), 키는 필요할 때만 | 그 서버 |
| **voin 내장 모델** (무료) | 설정 → 요약의 목록에서 모델 내려받기 (이 맥 메모리에 맞는 모델에 "추천" 표시) | 이 맥 안 |
| Ollama | Ollama 설치·실행, 모델 하나 이상 받기 | 이 맥 안 |

자동은 위 목록 순서대로 쓸 수 있는 첫 번째를 씁니다. API 키·구독 로그인의 모델은 앱을 켤 때와 하루에 한 번 회사의 모델 목록을 받아, 자동이면 가장 새 세대의 주력 모델을 고릅니다(`lib/model-ranking.mjs`). 직접 고른 모델은 바꾸지 않고 새 모델이 나오면 알리며, 고른 모델이 없어지면 자동 선택으로 대신 씁니다.

voin 내장 모델(`lib/summary-catalog.mjs`, `lib/local-llm.mjs`)은 Mi:dm 2.0 Mini(8GB 맥)·Gemma 4 E4B(16GB)·Qwen3.5 9B·Gemma 4 12B(24GB 이상) 중에서 고릅니다. 정답이 있는 합성 회의(`samples/5명-합성회의-정답.md`)로 후보 10개를 비교해 골랐고, 장단점은 그 결과입니다. 다시 비교하려면 `scripts/compare-summary-models.mjs`를 씁니다. ChatGPT·Grok 로그인은 공식으로 다른 앱에 열린 방식이 아니라(사용자 결정으로 hermes-agent 방식을 차용), OpenAI·xAI가 막으면 예고 없이 안 될 수 있습니다. ChatGPT 쪽 요청은 Codex CLI처럼 보이는 머리글(`originator: codex_cli_rs`)을 붙여야 Cloudflare에서 막히지 않습니다.

## 동작 방식

1. **녹음 중**: 저장 폴더에 기록 파일이 녹음 시작과 함께 생기고, 말이 멈출 때마다 받아쓴 줄이 바로 저장됩니다(마이크·화상회의 따로). 음성은 앱 데이터 폴더(`~/Library/Application Support/voin/tmp/`)에 임시로 저장됩니다.
2. **정리**(녹음 종료 후): 음성에서 "누가 언제 말했는지" 구간을 찾고, 구간마다 다시 받아써서 같은 파일을 화자별 기록으로 바꿉니다. 마이크 쪽은 "화자 1, 2…", 화상회의 쪽은 "원격 1, 2…". 1시간 녹음은 몇 분 걸립니다. 정리 중에 앱이 꺼져도 다음 실행 때 이어서 합니다.
3. **음성 파일**: 기본은 지웁니다. 설정에서 '음성 파일도 보관'을 켜면 기록 옆 `첨부/`로 옮깁니다.
4. **요약**: 같은 파일 맨 위 `## 요약`에 붙입니다(별도 파일 아님). 받아쓴 내용은 그 아래 `## 기록`.
5. **Obsidian 연결**(보관함 안에 저장할 때): 그날 데일리 노트 `[[2026-10-16]]`, 같은 제목의 직전 기록, 실제 이름으로 바꾼 화자 `[[홍길동]]`을 속성(daily·previous·participants)으로 넣고, 요약에 나온 낱말 중 보관함에 이미 있는 노트 이름(제목·별칭 포함)을 `[[링크]]`로 바꿉니다(`lib/obsidian-links.mjs`). 없는 노트는 만들지 않습니다. 화자 이름을 바꾸면 다시 연결합니다.
6. **팀 공유 폴더**: 요약·연결까지 들어간 최신본을 복사합니다(음성 제외).

기록 화면 위쪽 **참석자 카드**에서 이름을 붙입니다. 화자마다 ▶ 목소리(정리할 때 화자별로 남겨 둔 몇 초짜리 조각 3개, `~/Library/Application Support/voin/voices/`), 말한 시간·비율, 대표 발언(누르면 그 위치로 이동)이 보입니다. 본문의 화자 이름을 눌러도 그 화자 칸으로 갑니다. 요약 뒤에는 요약 도구가 기록 속 자기소개·호칭("김과장님?" 뒤 바로 대답 등)을 근거로 **이름 후보**를 찾아 카드에 보여 주고, 누르면 적용됩니다(근거가 없으면 추천하지 않음, 카드의 "이름 추천받기"로 다시 찾기). 이름을 넣으면 기록·요약·참석자 링크가 함께 바뀌고, 모두 붙이면 카드가 접힙니다. 목소리 조각은 보관함·팀 폴더에 넣지 않습니다.

사용 모델:
- 받아쓰기: 설정 → **받아쓰기 모델**에서 고릅니다(`lib/model-catalog.mjs`). 모두 무료이고 이 맥에서만 돌며, Handy가 Hugging Face에 올린 GGUF 파일을 커밋·SHA-256으로 고정해 받습니다. 기본은 Nemotron 3.5입니다.

  | 모델 | 크기 | 1시간 녹음 처리 | 실시간 스트리밍 | 시험에서 본 특징 |
  | --- | --- | --- | --- | --- |
  | Nemotron 3.5 (기본) | 751MB | 약 30초 | 지원 | 빠름. 영어 약어를 한글 소리로 적음 |
  | Qwen3-ASR 0.6B (추천) | 850MB | 약 1분 30초 | 미지원 | 문장이 가장 자연스러움. 잡음에 말을 지어냄 |
  | Qwen3-ASR 1.7B | 1.5GB | 약 2분 20초 | 미지원 | 0.6B와 비슷하거나 조금 나음. 메모리 16GB 권장 |
  | Whisper large-v3 turbo | 886MB | 약 3분 | 미지원 | 문장부호 자연스러움. 짧은 소리에 영어 문장을 지어냄 |
  | Whisper large-v3 | 1.2GB | 약 5분 | 미지원 | turbo보다 낫지 않았음 |
  | Whisper small | 270MB | 약 1분 30초 | 미지원 | 가벼움. 오인식 많음 |
  | SenseVoice Small | 250MB | 약 20초 | 미지원 | 가장 빠름. 띄어쓰기가 크게 깨짐 |

  2026-10-15 실제 회의 녹음(노트북 마이크, 한국어 5분)으로 비교했습니다(`scripts/compare-models.mjs`). 정답 대본이 없어 정확도는 결과를 읽고 판단했습니다. Moonshine 한국어는 짧은 발화에 "audiotext"만 내놓아 뺐습니다.
- 모델은 하나만 불러와 마이크·화상회의·파일 불러오기가 함께 씁니다. 말이 멈추면 그 문장을 받아쓰고(실시간 스트리밍을 지원하는 모델도 같은 방식), 말하는 중에는 1.5초마다 미리보기 자막을 보여 줍니다.
- 찾는 순서: `MODEL_PATH` 환경변수 → 앱 안(`models/`) → 내려받은 모델(`~/Library/Application Support/voin/models/`) → Handy 앱이 받아 둔 Hugging Face 캐시.
- 화자 분리: sherpa-onnx + pyannote segmentation 3.0 + 3D-Speaker ERes2Net(`models/`, 약 46MB). pyannote로 구간을 잘게 나누고, 구간별 목소리 특징을 직접 묶은 뒤(유사도 0.5), 말한 시간이 전체의 3%(3~20초) 미만인 묶음은 가장 가까운 화자에 붙입니다(`lib/diarize-worker.mjs`).
  - 실제 회의(노트북 마이크, 4명, 52분): 정확히 4명. sherpa 기본 묶기로는 135명으로 쪼개졌습니다. 정리 시간 약 3분.
  - 합성 음성 12명: 인원을 지정하면 24문장 중 22개, 자동이면 8명으로 판단(16개). 짧게 말한 사람이 많은 회의는 설정에서 인원을 지정하면 정확해집니다.

## 알아 둘 점

- 녹음이 끝나면 화자 분리 정리에 몇 분 걸립니다(52분 회의 약 3분). 그 사이 앱을 꺼도 다음 실행 때 이어서 정리합니다(`~/Library/Application Support/voin/tmp/`의 작업 기록). 녹음 중에 꺼도 그때까지의 녹음으로 정리합니다.
- 로그(`~/Library/Logs/voin.log`)는 실행마다 이어 쓰고, 녹음 시작·종료·정리 완료 시각을 남깁니다.

- 화상회의 소리를 함께 녹음할 때는 이어폰을 쓰세요. 스피커로 들으면 상대방 말이 마이크에도 들어가 두 번 기록됩니다.
- 받아쓰기 모델은 용어 사전(자주 쓰는 이름 등록)을 지원하지 않습니다.
