팀 공유

사본을 저장할 공유 폴더녹음이 끝나면 이 폴더에도 기록 사본을 저장합니다(음성 파일 제외). OneDrive·Google Drive·NAS나 팀이 함께 쓰는 보관함 폴더를 지정하세요. 비워 두면 사용하지 않습니다.

기록 형식

Obsidian 속성 넣기날짜·시간·참석자·태그를 파일 맨 위에 적습니다.
태그쉼표로 여러 개를 적을 수 있습니다.
음성 파일도 보관기록 옆 '첨부' 폴더에 WAV로 저장합니다(1시간에 약 115MB). 끄면 글만 남기고 음성은 지웁니다.

받아쓰기 모델

모두 무료이고 이 맥 안에서만 동작합니다. 한 번 내려받으면 인터넷 없이 씁니다. 속도와 정확도는 실제 회의 녹음(노트북 마이크, 한국어 5분)으로 이 맥(M 시리즈)에서 잰 결과입니다.

받아쓰기

언어한 언어로 고르면 다른 언어로 한 말은 기록에서 빠집니다. 외국어가 섞이는 회의만 자동 감지로 두세요(한국어 문장 일부를 다른 언어로 잘못 적을 수 있습니다).
기록 다듬기녹음이 끝나고 정리할 때 "음", "어", "um" 같은 군말과 바로 반복한 말을 기록에서 지웁니다. 끄면 들린 그대로 남깁니다.
외국어 번역녹음이 끝나고 정리할 때 외국어로 한 말 아래에 한국어 번역을 붙입니다. voin 내장 모델(Gemma 4 E4B·Qwen3.5 9B·Gemma 4 12B)로 이 맥 안에서 번역합니다.
문장 나누는 기준말이 이만큼 멈추면 실시간 자막에서 줄을 바꿉니다.

화자 분리

누가 말했는지 구분하기녹음이 끝나면 목소리별로 "화자 1, 화자 2…"로 나눕니다. 1시간 녹음은 몇 분 걸립니다.
참석 인원대체로 '자동'이 더 정확합니다.

화자 분리 모델 파일이 없습니다. 앱을 다시 설치하세요.

요약

녹음 정리가 끝나면 한 줄 요약·핵심 내용·결정 사항·할 일·남은 질문을 기록 맨 위에 붙입니다. Ollama 말고는 기록 내용이 해당 회사 서버로 보내집니다. 받아쓰기와 화자 분리는 계속 이 맥 안에서만 합니다.

요약 방법자동은 아래 목록 순서대로 쓸 수 있는 첫 번째를 씁니다.

설치된 명령줄 도구 이미 로그인한 도구를 그대로 씁니다

구독 로그인 hermes-agent처럼 Codex·Grok CLI의 로그인을 빌려 씁니다. 공식 지원 방식이 아니라 회사 정책에 따라 막힐 수 있습니다

이 맥에서 (외부 전송 없음)

voin 내장 요약 모델 무료로 이 맥 안에서 요약합니다. 내려받은 모델 중 '사용하기'로 고른 것을 씁니다

API 키 키는 맥 키체인에 저장되고 화면에 다시 보이지 않습니다. 사용량만큼 해당 회사에 요금이 나갑니다

아무 앱에 받아쓰기

받아쓰기 단축키어느 앱에서든 누르면 듣기 시작, 다시 누르면 받아쓴 글을 커서 자리에 붙여넣습니다. 처음 한 번 손쉬운 사용 권한이 필요합니다.
군말 지우기"음", "어,", "um", "uh" 같은 말과 바로 반복한 말을 지웁니다. 회의록은 원문 그대로 둡니다.
용어 사전한 줄에 하나씩 틀리게 들리는 말 => 바른 말. 바른 말만 적으면 받아쓰기 힌트로만 씁니다. 회의록과 받아쓰기 모두에 적용됩니다.

음성 작업

작업 모드에서 말하면 받아쓴 글을 아래 도구에 보내 같은 대화를 이어 가며 일을 시킵니다. 도구에 등록해 둔 MCP 서버·스킬·설정을 그대로 씁니다. 말한 내용과 작업 폴더의 파일이 그 도구의 회사(OpenAI·Anthropic) 서버로 보내집니다.

작업 도구
작업 폴더작업 버튼을 누르면 목록에서 고릅니다. 폴더마다 대화가 따로 이어집니다.
권한잘못 알아들은 말로 위험한 일이 실행되지 않도록, 폴더 밖 수정·네트워크·명령은 기본으로 승인을 받습니다.
답변 소리로 듣기답의 첫 문장을 맥 음성으로 읽어 줍니다.
말하기 단축키다른 앱을 쓰는 중에도 누르면 듣기 시작, 말이 멈추면 자동으로 보냅니다.
