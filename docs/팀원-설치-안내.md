# voin 설치·사용 안내

voin(voice in)은 회의·인터뷰·메모 녹음을 받아써서 기록(Markdown 파일)으로 남기고, 말로 Codex·Claude Code에 일을 시키는 맥 앱입니다. 녹음이 끝나면 누가 말했는지 나누고, 요약을 붙이고, Obsidian 노트와 연결합니다.

- **이 맥 안에서만 처리:** 녹음, 받아쓰기, 화자 분리
- **외부로 보내질 수 있음:** 요약과 화자 이름 추천. 설정에서 고른 방법에 따라 기록 내용이 Anthropic·OpenAI·xAI 등의 서버로 갑니다. Ollama를 쓰거나 요약을 끄면 보내지 않습니다.

## 1. 필요한 환경

- Apple Silicon 맥(M1 이후). 인텔 맥에서는 실행되지 않습니다.
- macOS 14.4 이상
- 여유 공간 약 2GB, 메모리 8GB 이상 (큰 받아쓰기 모델은 16GB 권장)

## 2. 설치

받은 DMG 파일은 두 가지 중 하나입니다.

| 파일 | 차이 |
| --- | --- |
| `voin-0.1.0.dmg` (약 100MB) | 첫 실행 때 받아쓰기 모델(751MB)을 내려받습니다. 인터넷이 필요합니다. |
| `voin-0.1.0-모델포함.dmg` (약 780MB) | 모델이 들어 있어 설치하면 바로 씁니다. 회사망에서 내려받기가 막힐 때 씁니다. |

1. DMG를 더블클릭해 열고, **voin**을 옆의 **응용 프로그램** 폴더로 끌어다 놓습니다. 복사가 끝나면 Finder 사이드바의 'voin 0.1.0' 옆 꺼내기 버튼을 누릅니다.
2. voin을 실행합니다. 처음에는 "Apple이 확인할 수 없다"는 경고가 뜹니다. 사내용 앱이라 Apple 공증을 받지 않았기 때문입니다.
   1. 경고 창에서 **완료**를 누릅니다.
   2. **시스템 설정 → 개인정보 보호 및 보안** 맨 아래에서 'voin'의 **그래도 열기**를 누르고 암호(또는 Touch ID)로 확인합니다.
   3. 한 번 허용하면 다음부터는 그냥 열립니다.
3. (모델 없는 DMG만) 창 위쪽에 "받아쓰기 모델이 없습니다"가 뜨면 **내려받기**를 누릅니다.
   - 몇 분 걸립니다.
   - **취소**했다가 나중에 **이어 받기**로 받던 곳부터 계속할 수 있습니다.
   - 회사망에서 실패하면 휴대폰 핫스팟 같은 다른 네트워크에서 **다시 시도**를 누르세요.
   - 오른쪽 위에 초록 점과 모델 이름이 보이면 준비된 것입니다.

## 3. 처음 녹음할 때 허용할 권한

- **마이크:** 녹음을 시작하면 macOS가 묻습니다. **허용**을 누릅니다.
- **화면 및 시스템 오디오 녹음:** '화상회의 소리 포함'을 켜고 녹음하면 묻습니다. 허용해야 Zoom·Teams 상대방 목소리가 기록됩니다. 화면은 녹화하지 않고 소리만 받습니다.

## 4. 기본 사용법

voin 창은 작은 막대 하나입니다. 왼쪽에 **● 녹음**과 **✦ 작업**, 가운데에 지금 상황(파형·들은 말·작업 진행, 평소엔 회의 앱·이어폰 여부), 오른쪽에 **💬 실시간 글 · ☰ 기록 · ⚙ 설정**이 있습니다. 오른쪽 버튼을 누르면 창이 아래로 늘어나며 열리고, 다시 누르거나 Esc로 닫습니다.

| 하고 싶은 일 | 방법 |
| --- | --- |
| 녹음 시작/종료 | **● 녹음** 버튼. 다른 앱을 쓰는 중이면 **⌥R** |
| 받아쓰는 글 보기 | 녹음 중에는 막대에 파형만 보입니다. 글은 **💬** |
| 녹음 파일 받아쓰기 | **☰** 목록 위 ⬇ 아이콘(⌘O), 또는 창에 파일(m4a·mp3·wav)을 끌어다 놓기 |
| 말로 일 시키기 | **✦** (어디서든 **⌥V**) → 마이크가 켜진 채로 대화. "띵" 뒤에 말하면 보내고, 답을 소리로 읽은 뒤 다시 "띵". 다시 누르면 끝. 대화 전체는 **💬**. 6번 참고 |
| 기록 찾기 | **☰** 목록(오늘·어제·날짜별)과 검색칸 |
| 메뉴 막대에서 조작 | 화면 오른쪽 위 파형 아이콘. 녹음 중에는 🔴와 경과 시간, 정리 중에는 ⏳ |
| 설정 | 오른쪽 위 톱니바퀴(⚙), 또는 ⌘, |

- **창을 닫아도 앱은 계속 실행됩니다.** 메뉴 막대에 남아 있고, 녹음 중이면 녹음도 계속됩니다. 완전히 끄려면 ⌘Q를 누르거나 메뉴 막대 아이콘 → **voin 종료**를 고릅니다.
- **화상회의 소리를 함께 녹음할 때는 이어폰을 쓰세요.** 스피커로 들으면 상대방 말이 마이크에도 들어가 두 번 기록됩니다.

## 5. 녹음이 끝나면 일어나는 일

1. **정리:** 누가 말했는지 나누고 다시 받아써서 "화자 1, 화자 2…"로 정리합니다. 1시간 녹음은 몇 분 걸립니다. 정리 중에 앱을 꺼도 다음 실행 때 이어서 합니다.
2. **요약:** 기록 맨 위에 한 줄 요약·핵심 내용·결정 사항·할 일·남은 질문이 붙습니다. 별도 파일이 아니라 같은 파일 안에 붙습니다. (8번 설정 필요)
3. **이름 후보:** 대화에서 이름이 불렸으면 화자별 이름 후보를 찾아 둡니다.
4. **Obsidian 연결:** Obsidian 보관함에 저장했다면 아래 노트와 자동으로 링크됩니다.
   - 그날 데일리 노트
   - 같은 제목의 이전 기록
   - 참석자 (실제 이름을 붙인 경우)
   - 요약에 나온 기존 노트
5. **팀 공유 폴더:** 지정해 두었다면 요약·연결까지 들어간 사본을 복사합니다.

받아쓴 말이 하나도 없는 녹음(잘못 누른 짧은 녹음 등)은 기록을 남기지 않습니다. 녹음 음성은 기본적으로 지웁니다. 설정 → 기록 형식 → **음성 파일도 보관**을 켜면 기록 옆 `첨부/` 폴더에 남깁니다.

## 6. 말로 일 시키기 (작업)

설정 → **음성 작업**에서 먼저 정합니다.
- **작업 도구:** Codex 또는 Claude Code. 이 맥에 설치하고 로그인해 둬야 합니다. 도구에 등록해 둔 MCP 서버·스킬을 그대로 씁니다.
- **작업 폴더:** ✦를 누르면 먼저 "어느 폴더에서 일할까요?" 목록이 뜹니다. **+ 폴더 추가**로 Finder에서 폴더를 고르면 목록에 남고(파일을 옮기거나 복사하지 않음), **×**로 목록에서 뺄 수 있습니다(폴더는 그대로). 폴더를 누르거나 숫자 1–9·Enter(맨 위)를 누르면 그 폴더의 대화가 열리며 바로 듣기 시작합니다. ⌥V는 목록 없이 마지막 폴더로 바로 시작합니다. 폴더마다 대화와 기록이 따로 이어집니다.
- **권한:** 기본은 "폴더 안 수정만 바로, 나머지는 승인". 잘못 알아들은 말로 위험한 일이 실행되지 않도록, 폴더 밖 수정·네트워크·명령은 화면의 **허용/거절**을 눌러야 실행됩니다.
- **답변 소리로 듣기:** 답의 앞부분(최대 3문장)을 맥 음성(유나)으로 읽어 줍니다. 코드·표·주소는 읽지 않으니 화면(💬)에서 보세요.

**대화하듯 씁니다.** **✦ 작업**을 한 번 누르면(또는 ⌥V) 마이크가 켜진 채로 유지됩니다.
1. **"띵" 소리가 나고 "말하세요"가 보이면** 말합니다. 그 전에 한 말은 녹음되지 않습니다.
2. 말이 1.5초 멈추면 자동으로 보내고, 막대에 작업 진행이 보입니다.
3. 끝나면 답을 소리로 읽어 주고, 다 읽으면 다시 **"띵"** 합니다. 이어서 말하면 됩니다.
4. 그만하려면 **✦**를 다시 누릅니다. 2분 동안 아무 말이 없어도 꺼집니다(작업 중·답을 읽는 중은 세지 않음).

작업이 진행되는 중에 말하면, Codex는 하던 작업에 그 말을 더하고 Claude Code는 끝난 뒤 이어서 보냅니다. 답을 읽는 동안에는 voin이 자기 목소리를 받아쓰지 않도록 마이크 소리를 버립니다. 글로 입력해도 됩니다. 도구가 한 일은 "작업 단계 N개"를 누르면 보입니다. 작업 중에는 **멈춤**, 새로 시작하려면 **새 대화**를 누릅니다.

말한 내용과 작업 폴더의 파일은 고른 도구의 회사(OpenAI·Anthropic) 서버로 보내집니다.

## 7. 화자 이름 붙이기

기록을 열면 위쪽에 화자마다 카드가 있습니다. 기록을 처음부터 읽지 않아도 됩니다.

- **▶ 목소리:** 그 화자의 몇 초짜리 목소리를 들려줍니다.
- **말한 양:** 말한 시간과 비율, 횟수를 보여 줍니다. 발표자·질문자 같은 역할을 짐작할 수 있습니다.
- **대표 발언:** 누르면 기록의 그 위치로 이동합니다.
- **추천: ○○○:** 대화에서 이름이 불린 근거와 함께 보입니다. 누르면 바로 적용됩니다.
- **이름 칸:** 입력하고 Enter를 누르면 다음 카드로 넘어갑니다.

이름을 넣으면 기록 본문, 요약 속 이름, 참석자(Obsidian 링크)가 함께 바뀝니다. 한 사람이 두 화자로 나뉘었다면 두 카드에 같은 이름을 넣어 합치면 됩니다. 본문의 화자 이름을 눌러도 그 화자의 카드로 갑니다.

## 8. 요약 설정 (선택)

설정 → **요약**에서 방법을 고릅니다. **자동**은 아래 표에서 준비된 첫 번째 방법을 씁니다. 하나도 준비되지 않았으면 요약 없이 기록만 저장합니다.

| 방법 | 준비할 것 | 기록이 가는 곳 | 비용 |
| --- | --- | --- | --- |
| Claude Code | 설치 후 터미널에서 `claude` 실행해 로그인 | Anthropic | Claude 구독 사용량 |
| Codex | 설치 후 터미널에서 `codex login` | OpenAI | ChatGPT 구독 사용량 |
| ChatGPT 로그인 | 설정 → 요약 → ChatGPT 로그인의 **로그인** → 브라우저에 뜬 화면에 코드 입력·승인 (Codex 설치 불필요) | OpenAI | ChatGPT 구독 사용량 |
| Grok 로그인 | 설정 → 요약 → Grok 로그인의 **로그인** → 브라우저에서 승인 | xAI | SuperGrok·X Premium+ 구독 |
| API 키 (Anthropic·OpenAI·xAI Grok·Gemini·OpenRouter) | 설정 → 요약에 키 입력 → **저장** | 해당 회사 | 사용량만큼 과금 |
| Ollama | ollama.com에서 설치·실행 후 모델 하나 받기 | 이 맥 안 (전송 없음) | 없음 |

- **ChatGPT·Grok 로그인:** hermes-agent와 같은 방식으로 Codex CLI와 Grok CLI의 로그인을 빌려 씁니다. 회사가 공식으로 다른 앱에 열어 둔 방식이 아니라서, 예고 없이 막힐 수 있습니다. 그럴 때는 API 키나 Claude Code·Codex를 쓰세요.
- **Grok 로그인이 "API 사용이 허용되지 않음"으로 실패하면:** xAI가 일부 구독 등급에만 API 사용을 허용하는 경우입니다. console.x.ai에서 xAI API 키를 만들어 쓰세요.
- API 키와 로그인 정보는 맥 키체인에 저장되고, 화면에 다시 보이지 않습니다.
- 회사 정보 보호 정책상 외부 전송이 곤란한 기록은 요약을 **끄기**로 두거나 Ollama를 쓰세요.
- 저장된 기록은 기록 화면 오른쪽 위 **요약 만들기 / 다시 요약**으로 언제든 요약할 수 있습니다.

## 9. 받아쓰기 모델 고르기 (선택)

설정 → **받아쓰기 모델**에서 모델별 장단점, 크기, 처리 속도를 보고 내려받아 바꿀 수 있습니다.
- **Nemotron 3.5 (기본):** 가장 빠릅니다. 영어 약어를 한글 소리로 적는 경향이 있습니다(예: HRIS → 에이치 알 아이 에스).
- **Qwen3-ASR 0.6B (추천):** 시험한 모델 중 문장이 가장 자연스러웠습니다.

## 10. 파일이 저장되는 곳

| 무엇 | 위치 |
| --- | --- |
| 기록 (Markdown) | Obsidian을 쓰면 지금 열린 보관함 안 `녹음 기록` 폴더, 없으면 `문서/녹음 기록`. 설정 → 저장 위치에서 변경. ☰ 목록 위 폴더 아이콘으로 열기 |
| 목소리 조각 (이름 붙이기용) | `~/Library/Application Support/MeetingNotes/voices/` (보관함·팀 폴더에는 넣지 않음) |
| 받아쓰기 모델 | `~/Library/Application Support/MeetingNotes/models/` |
| 설정 | `~/Library/Application Support/MeetingNotes/settings.json` |
| 로그 | `~/Library/Logs/voin.log` |

## 11. 문제가 생기면

| 증상 | 확인할 것 |
| --- | --- |
| 앱이 열리지 않음 | 2번의 **그래도 열기** |
| 말로 시킨 일이 시작되지 않음 | 설정 → 음성 작업에서 작업 폴더를 골랐는지, 작업 도구가 "준비됨"인지 |
| 녹음 버튼이 눌리지 않음 | 오른쪽 위 모델 상태가 초록 점인지. 아니면 위쪽 알림에서 모델 내려받기 |
| 화상회의 소리가 기록되지 않음 | 시스템 설정 → 개인정보 보호 및 보안 → **화면 및 시스템 오디오 녹음**에서 'voin' 켜기 |
| ⌥R이 안 먹힘 | 다른 앱이 같은 단축키를 쓰는지. 설정 → 일반에서 다른 조합으로 변경 |
| 메뉴 막대 아이콘이 안 보임 | 노치 있는 맥북은 아이콘이 많으면 가려집니다. ⌘를 누른 채 다른 아이콘을 끌어 정리. 설정 → 일반 → **메뉴 막대에 아이콘 표시**가 켜져 있는지 확인 |
| 요약이 안 붙음 | 설정 → 요약에서 준비된 방법이 있는지(초록 글씨). 로그인한 뒤에는 **상태 다시 확인** |
| 그 밖의 오류 | 설정 → 정보 → **로그 파일 보기**로 `voin.log`를 담당자에게 보내기 |

## 12. 지우기

1. voin을 끕니다(⌘Q).
2. 응용 프로그램 폴더에서 voin을 휴지통으로 옮깁니다.
3. 받은 모델·설정·목소리 조각까지 지우려면 `~/Library/Application Support/MeetingNotes` 폴더도 지웁니다.

기록 파일은 저장 폴더에 그대로 남습니다.
